# Voz · Claude Design

## Principios

1. **Imperativo, directo.** "Entrena como los que ganan." No "te invitamos a entrenar".
2. **Frases cortas.** Si una frase no entra en una camiseta, sobra.
3. **Datos antes que adjetivos.** "+47% engagement" pesa más que "muchísimo más alcance".
4. **Tono de vestuario, no de oficina.** Te puedes hablar al usuario de tú, sin formalidad corporativa.
5. **Sin floritura.** No "innovador", "disruptivo", "vanguardia". Sí "rápido", "claro", "que funciona".
6. **Pregunta antes de afirmar (en covers).** Las portadas funcionan mejor empezando con `¿…?`.

## Estructura típica de un carrusel

| Slide | Función                | Ejemplo                              |
| ----- | ---------------------- | ------------------------------------ |
| 1     | Hook (pregunta)        | `¿Rigidez de cadera?`               |
| 2     | Diagnóstico breve       | El problema en 1 línea              |
| 3-5   | Tips numerados         | `01 Movilidad — sentadilla 60s`     |
| 6     | Stat o cita            | `83% de las lesiones…`              |
| 7     | Antes/Después o caso    | dos columnas                        |
| 8     | CTA final              | `¿Listo para subir de nivel?`       |

## Reglas de copy

- Números siempre en cifra: **3 claves**, no "tres claves".
- Porcentajes y unidades se escriben pegados: `83%`, `60s`, `+47%`.
- Mayúsculas sólo donde la tipografía display las imponga (uppercase visual,
  no en los textos de body).
- Eñe y acentos siempre presentes (el sector hispanohablante lo nota).
- Evita signos de exclamación en cadena. Uno está bien. Tres no.

## Vocabulario favorito

- **Sí:** rendimiento, performance, sesión, plan, prevención, dato,
  específico, individual, cuerpo, ritmo, base, élite, temporada,
  off-season, pre-season, sprint, fuerza, movilidad.
- **No:** holístico, sinergia, transversal, ecosistema, journey, partner,
  transformacional, paradigma, escalar (en sentido empresarial).

## Tono según contexto

| Pieza               | Tono                              |
| ------------------- | --------------------------------- |
| Carrusel educativo  | Profesor breve, sin dar lecciones |
| Cover hook          | Provocador con buen rollo         |
| Cita                | Solemne, sin moralina             |
| CTA final           | Directo, casi de vestuario        |
| Web hero            | Manifiesto en una frase           |
| Stories ad          | Urgencia útil, no urgencia falsa  |
